# 一掷千金 · Deal or No Deal

一个单文件的网页版《一掷千金》（Deal or No Deal）。26 个公文包，金额从 1 美分到 100 万美元，挑一个带走，但要先开掉剩下的 25 个。

## 怎么玩

双击 `deal-or-no-deal.html`，用浏览器打开即可。没有构建步骤，没有依赖，不需要联网。

- **上场**：从 26 个箱子里挑一个当自己的"命运之箱"（当时不知道里面有多少钱）。
- **逐轮开箱**：每轮开 6 / 5 / 4 / 3 / 2 / 1 / 1 / 1 / 1 个箱子。
- **银行家报价**：每轮开完，主持人转述银行家报价。**成交 DEAL** 拿钱走人，**拒绝 NO DEAL** 继续。
- **还价**：全场只有一次机会，提出更高的价格。银行家答应就成交，拒绝就继续开箱。
- **终局**：一直拒绝的话，最后打开自己的箱子，拿走里面的全额。
- **亲友团**：第三轮开箱结束后登场（10 个角色里随机抽 2–3 位，抽定后整局不变）。他们会报箱号、给建议——但决定权在你手里。
- **假设环节**：成交之后可以继续开箱，看银行家"本来会"出到多少。

点台词行可以跳过当前这句；右上角有规则、历史记录、设置（BGM / 音效音量），设置存在 localStorage 里。

## 另一个页面：实验室

顶部的「实验室」标签页是蒙特卡洛模拟，用来验证策略：

- 跑 1,000 / 10,000 / 50,000 局，对比「稳健派」（报价 ≥ 期望值 × 阈值就成交）和「保底派」（达到目标金额就收手）两种策略。
- 输出平均奖金、报价 / 期望值曲线、奖金分布、阈值扫描。
- 改任一控件自动重跑，不需要点按钮。

## 代码结构

`deal-or-no-deal.html` 内部按注释分节，从上到下依次是：

1. **数据 & 报价模型**（约 625 行）— `VALUES`（26 个金额）、`ROUNDS`（每轮开箱数）、`PCT`（各轮报价占期望值的比例区间）、`momentumOf`（本轮开出金额对下轮报价的加减）、`roundOffer`（报价取整规则）。
2. **人物**（658）— `slimCase` / `figure` / `familyFigure`，纯 SVG 剪影，无图片资源。
3. **阵容**（731）— 主持人是固定的，3 位模特从 15 个英文名里随机取，亲友团从 10 个角色里抽（夫妻不共存）。
4. **台词**（759）— 所有台词都是 `L` 对象里的池子，用 `pick(L.键)` 随机取；带 `{a}` 的在触发处替换成金额，`{n}` 换成箱号或剩余数。
5. **打字机**（807）— `speak(who, text, hold)` 逐字写入 `#dialogue`，`actorOf()` 负责把说话人解析到具体人物。
6. **音频**（874）— BGM + 音效，base64 内嵌，开关和音量存 localStorage。
7. **历史记录**（902）— 最近 120 局存在 localStorage。
8. **开箱大戏**（932）、**游戏状态**（986）— `G` 是全局状态对象；主流程是 `startGame` → `openCase`（循环）→ `bankerCall` → `endWithDeal` / `continueGame` → `revealFinal`。
9. **亲友团**（1180）、**银行家来电**（1202）、**结果**（1370）、**绑定**（1401）、**实验室**（1472）、**启动**（1730）。

三条改代码时容易踩的约定：

- **右栏面板高度恒定**：右栏内容包在 `.railIn{position:absolute;inset:0}` 里，报价记录增长、还价面板展开、假设条出现都不会改变面板高度。改右栏 DOM 时保持这个结构。
- **还价面板是浮层**（`.cpanel`），不占布局高度。
- **窄屏覆盖要写全选择器**：`.ggrid .railIn{...}`，`@media` 本身不提升优先级，写裸 `.railIn` 会被后面的规则盖掉。

## 修改指南

- **改台词**：只动 `L` 对象（约 760–800 行）里的数组，别动调用处。改完同步更新 `台词逻辑说明.md`。
- **改报价松紧**：调 `PCT` 或 `randPct`。想验证效果直接去实验室跑模拟。
- **改人物外观**：`figure(o)` 接受 `skin / main / hair / trim / hairStyle / male / suit` 等参数。
- **加音效**：往 `window.AUDIODATA` 里加 base64 字段，然后 `SND.play('名字', 音量)`。
